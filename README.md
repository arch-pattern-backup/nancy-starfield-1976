HOSTING ON GITHUB PAGES (free, no account needed for recipient)
---------------------------------------------------------------
1. Create a free account at https://github.com
2. Create a new repository, e.g. "starfield-1976-nancy"
3. Upload all HTML files to the repository
4. Go to Settings > Pages > Source: Deploy from branch > main / root
5. GitHub gives you a URL like:
      https://yourusername.github.io/starfield-1976-nancy/
6. Send Nancy that link — it works on any device, any browser.
   No app to install, no login required.
